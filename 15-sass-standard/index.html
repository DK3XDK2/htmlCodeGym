Chuyển đổi CSS sang SASS chuẩn

Dự án này đã được cấu trúc lại hoàn toàn từ file CSS gốc sang kiến trúc SASS nhiều tầng chuyên nghiệp (Abstracts, Base, Layout, Components).

Mã nguồn sử dụng đầy đủ biến ($variables), Mixins (@mixin & @include), lồng nhau (nesting) và được kết hợp thông qua file main.scss.
