CHƯƠNG TRÌNH HỌC CHUẨN ĐẦU RA

Lộ Trình Đào Tạo Full-Stack 20 Tuần

Chương trình được tinh gọn, loại bỏ lý thuyết hàn lâm, tập trung vào các công nghệ được doanh nghiệp săn đón nhiều nhất.

Module 1: Nền tảng lập trình & Lập trình Web căn bản

4 Tuần (Tuần 1 - 4)

Làm quen với tư duy thuật toán, cấu trúc điều khiển, xử lý mảng và hàm. Xây dựng giao diện web chuẩn responsive với HTML5, CSS3, Flexbox/Grid và JavaScript ES6+. Quản lý mã nguồn nhóm cùng Git & GitHub.

HTML5 / CSS3
JavaScript ES6+
Git / GitHub
Bootstrap Responsive

Module 2: Lập trình hướng đối tượng (OOP) & Cấu trúc dữ liệu

4 Tuần (Tuần 5 - 8)

Thấu hiểu bản chất 4 tính chất OOP (Đóng gói, Kế thừa, Đa hình, Trừu tượng). Làm chủ Generic, Collection Framework, xử lý ngoại lệ (Exception), I/O File, Clean Code và kiểm thử đơn vị với Unit Testing (JUnit).

OOP Core (Java / TypeScript)
Clean Code
Data Structures & Algo
JUnit Testing

Module 3: Cơ sở dữ liệu & Lập trình Web Backend

6 Tuần (Tuần 9 - 14)

Thiết kế cơ sở dữ liệu quan hệ với MySQL / PostgreSQL. Xây dựng dịch vụ RESTful API bảo mật cao với Spring Boot hoặc Node.js / Express, xử lý JWT Authentication, phân quyền người dùng và tích hợp dịch vụ thanh toán.

MySQL / RDBMS
Spring Boot / MVC
RESTful API
Spring Security & JWT

Module 4: Phát triển Web Full-Stack hiện đại

4 Tuần (Tuần 15 - 18)

Kết nối frontend và backend thành hệ thống hoàn chỉnh. Xây dựng Single Page Application (SPA) với React / Angular, quản lý State, tối ưu hiệu năng tải trang và triển khai ứng dụng lên nền tảng đám mây (AWS / Vercel).

React / Angular
State Management
Full-stack Integration
Cloud Deployment

Module 5: Đồ án tốt nghiệp thực chiến Scrum & Chuẩn bị tuyển dụng

2 Tuần (Tuần 19 - 20)

Tham gia nhóm phát triển dự án thực tế theo quy trình Scrum chuẩn mực: Daily meeting, Sprint Planning, Retrospective. Hoàn thiện e-Portfolio, luyện tập phỏng vấn kỹ thuật (Mock Interview) và tham gia tuyển dụng trực tiếp tại Hiring Day.

Scrum / Agile
Capstone Project
Mock Interview
Hiring Day
DỊCH VỤ VIỆC LÀM TẠI CODEGYM

Cam Kết 100% Việc Làm Bằng Hợp Đồng

CodeGym đồng hành cùng bạn từ khi bắt đầu cho đến khi nhận được thư mời làm việc (Offer Letter) từ doanh nghiệp. Nếu không có việc trong 45 ngày, hoàn lại 100% học phí.

1

Tinh chỉnh kỹ năng

Đánh giá năng lực chuyên môn, hoàn thiện hồ sơ dự án thực tế trên GitHub và tạo CV công nghệ chuẩn mực thu hút nhà tuyển dụng.

2

Tư vấn nghề nghiệp 1-1

Chuyên viên Career Coach định hướng lộ trình thăng tiến cá nhân, xác định điểm mạnh và lựa chọn doanh nghiệp phù hợp với nguyện vọng.

3

Luyện tập phỏng vấn

Tham gia các buổi Mock Interview thực chiến với các Tech Lead, luyện kỹ năng trả lời thuật toán, live-coding và thương lượng mức lương.

4

Hiring Day & Nhận việc

Phỏng vấn trực tiếp tại ngày hội tuyển dụng độc quyền của CodeGym. 100% học viên nhận được lời mời làm việc với mức lương khởi điểm hấp dẫn.
