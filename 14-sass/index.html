Thực Hành SASS / SCSS CLI & npm

Trang web được thiết kế bằng SASS (SCSS) và tự động biên dịch sang CSS tiêu chuẩn

1. SASS Variables

Quản lý màu sắc, kiểu chữ và các kích thước chuẩn bằng biến $variable tập trung trong file _variables.scss.

2. Nesting & Hierarchy

Cấu trúc CSS dạng lồng nhau giúp code rõ ràng, phản ánh chính xác cấu trúc cây DOM của HTML.

3. SASS CLI & Watch Mode

Biên dịch tự động thông qua câu lệnh sass scss/:css/ --watch mỗi khi có thay đổi trong file SCSS.
